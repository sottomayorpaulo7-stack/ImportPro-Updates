# ImportPro: atualizações

Este repositório guarda só as versões publicadas do ImportPro:

- `versao.json`: a versão mais recente (o programa lê-o ao abrir).
- `importpro.zip`: os ficheiros dessa versão, instalados automaticamente.
- `Instalar ImportPro.bat`: instalador para a primeira instalação num PC novo.
- `Desinstalar ImportPro.bat`: apaga o ImportPro do computador (pasta do programa, chave do Firecrawl, sessão, favoritos, ajustes e atalhos).

Não contém chaves, contas nem dados de utilizadores.
